How API routing works

Each tool key (e.g. like_send) maps to one enabled API config. When a user submits a tool request on the website, it is placed in the Firebase request queue. The Discord bot polls this queue, looks up the matching API config by tool key, makes the HTTP call, and writes the result back to Firebase. The website polls Firebase until the result appears.

Use {uid}, {region}, {name} etc. as URL placeholders — they are replaced with the actual request parameters.
